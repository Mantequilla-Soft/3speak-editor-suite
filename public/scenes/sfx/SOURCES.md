# Sound effects (all CC0 / public domain, no attribution required)
- swish-1..4.wav: cut from "SWSH_Processed swishes_CS_USC.wav", SSE Library: SWOOSHES, Internet Archive
  https://archive.org/details/SSE_Library_SWOOSHES (license: https://creativecommons.org/publicdomain/zero/1.0/)
- whoosh-1..3.wav: cut from "WHSH_Scifi swish by_CS_USC.wav", same library and license
- tick.wav: "Woosh" by 1bob, freesound.org/s/831936, CC0 (via https://remotion.media/whoosh.wav)
Each cut: 0.85-1.15 s, short fade in/out, stereo 48 kHz, normalised to -3 dBFS peak (loudness is set at mix time).
- trans-1..5.wav: 0.4 s cut around the peak of whoosh-1.wav, pitched x1.00 / 1.12 / 0.94 / 1.20 / 1.06 (asetrate), for scene
  transitions (the fade-through is only 0.25 s, so the long whooshes outlasted it). Same CC0 source.
- click-1..3.wav (word pops): click_002 / click_003 / click_005, and type-1..3.wav (typing): tick_001 / tick_004 / tick_002,
  from "Interface Sounds" by Kenney (www.kenney.nl), CC0 (https://kenney.nl/assets/interface-sounds). Mono to stereo,
  48 kHz, -3 dBFS peak, 30 ms tail pad.
- hit-1..3.wav (punchy word slams, e.g. kinetic): impactPunch_heavy_000 / 001 / 002 from "Impact Sounds" by Kenney
  (www.kenney.nl), CC0 (https://kenney.nl/assets/impact-sounds). Mono to stereo, 48 kHz, -3 dBFS peak, 30 ms tail pad; peak 20 ms in.
